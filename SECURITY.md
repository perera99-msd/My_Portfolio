# 🔐 Security Policy

## Supported Versions
Security updates are currently provided for the latest version on the main branch.

## Reporting a Vulnerability
If you discover a security issue, please report it privately:
- Email: msdperera99@gmail.com

Please include:
- A clear description of the vulnerability
- Reproduction steps or proof of concept
- Potential impact
- Suggested mitigation (if available)

## Disclosure Process
1. Acknowledgement within 3-5 business days
2. Initial triage and severity assessment
3. Fix development and verification
4. Responsible disclosure after fix release

Please do not open public issues for security vulnerabilities.
